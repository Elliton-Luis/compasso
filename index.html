          O que é o Compasso

          Camada pessoal de planejamento financeiro. Ele não substitui o app do banco: responde "quanto do meu dinheiro já está comprometido, agora e no futuro?"

          A regra é: cadastro simples, análise poderosa. Você informa os fatos (descrição + valor + parcelas + início) e o app calcula parcelas, faturas, disponibilidade e projeções.

          Conta: senha x código

          • Senha
            Criada por você no cadastro. É o que você digita para entrar. O 👁️ mostra o que foi digitado.
          • Código (ex.: AB12-CD34)
            Gerado pelo app, não é senha e não abre nada. Prova que o perfil é seu e é pedido para apagar tudo. Anote e guarde (Ajustes → Perfil).
          • Lembrar de mim
            Dispensa a senha até o prazo expirar (1h a 30 dias, configurável). Só em aparelho pessoal.

          Tela Início (dashboard)

          • Este mês
            Receita, reservado, comprometido e disponível = receita − reservado − compromissos.
          • Gráfico mensal
            Barras do comprometido nos próximos 12 meses. A barra cheia é o mês mais pesado.
          • Resumo
            % da receita comprometida, mês mais pesado, até quando o dinheiro está comprometido e total futuro.
          • Faturas (cartão)
            Só compromissos do tipo Cartão. Mostra até quando o cartão já está comprometido.
          • Por categoria
            Rosca com para onde vai o dinheiro em 12 meses.
          • Linha do tempo
            Próximas cobranças (com nº da parcela, ex.: 2/6) — dá para ver quando cada uma termina.

          Tela Novo (cadastrar)

          • Compromisso
            Descrição + valor + tipo + parcelas + início. O app calcula valor da parcela, meses afetados e último mês.
          • Cartão x Externo
            Cartão entra nas faturas. Externo (ex.: combinado fora do cartão) é projetado normalmente, mas fora da fatura.
          • Parcelas
            R$ 200 em 2x = 2 meses de R$ 100. Centavos quebrados vão para as primeiras parcelas (R$ 200 em 3x = 66,67 + 66,67 + 66,66).
          • Recorrente
            Marque "mensal recorrente" para repetir todo mês (ex.: academia). O valor passa a ser mensal. "Fim" é opcional.
          • Salário mensal
            Vale para todos os meses da projeção e das simulações. Para ajustar um mês específico (13º, férias), use "Receita do mês" — vazio = vale o salário.
          • Simular antes de salvar
            Mostra como fica o disponível deste mês (antes → depois), o mês mais pesado e o total futuro. Não salva nada.

          Telas Meses e Ajustes

          • Meses
            Projeção detalhada: toque em cada mês para ver receita, reservado, cartão, externo e cada compromisso que o compõe.
          • Perfil
            Trocar o nome do topo e copiar o código de cadastro.
          • Aparência
            Modo claro (branco pastel) ou escuro (azul escuro) + 12 cores de fundo. Ficam salvos neste aparelho.
          • Senha e sessão
            Trocar senha, duração do "lembrar", esquecer o aparelho e bloquear agora.
          • Backup
            JSON = backup completo (exportar/importar). Markdown = resumo legível. PDF = relatório via impressão.
          • Apagar tudo
            Exige o código de cadastro. Sem o código, não apaga.

          Segurança e dados

          Tudo fica no seu aparelho (LocalStorage), sem conta e sem nuvem. Os dados financeiros são criptografados (AES-GCM); a senha nunca é guardada — exceto com "lembrar" ativo (ofuscada, com validade). Funciona offline depois de instalado (PWA).
